## 一个顺带的重要发现：之前的性能读数被并发污染了

本轮干净环境下的实测，与 WO-C5/E4 并发期间的读数对比：

| 指标 | 并发期间 | 本轮干净环境 |
|---|---:|---:|
| 100 单位中位 | 3.684 ms | **2.480 ms** |
| 200 单位中位 | 10.904 ms | **7.136 ms** |
| 400 单位中位 | 37.306 ms | **20.685 ms** |
| doubling ratios | 2.96x / 3.42x | **2.88x / 2.90x** |

**低了约 40%。** 所以 WO-C5 当初「需要换干净机器复测」的直觉是对的，只是它没同时意识到
场景也过时了。两个原因叠在一起，才造成 31.6 ms 那个吓人的读数。

**教训**：并发会话期间产出的任何绝对性能数字都不可信，只有比值和复杂度结论还能用。
以后性能验收应当在确认无并发后单独跑一次。
