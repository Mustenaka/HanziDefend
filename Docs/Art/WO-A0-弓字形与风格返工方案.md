# WO-A0 ·「弓」字形与风格返工方案（已废弃）

> **废弃记录（2026-08-12）：**用户实测了本文提出的全部方案，均不满意。本方案及关联的漆绘国潮、木版门神、焦墨矿彩、皮影武将 prompt 不再使用。后续以用户提供的多张效果参考图主导生成，文字只补充玩法与技术约束。本文仅为失败试验留档。

## 1. 现有产出的失败现象

现有“弓-第一版-效果不好.png”可以概括为「Q 版国潮贴纸 / 奶油釉面扁平卡通」：巨大、静止的宣白「弓」字占据几乎全部视觉重心，两侧挂着两个微型武士，一根细箭横穿中央，一条细折线被当作弓。大图尚能认字，但角色、武器和动作并没有形成同一个整体。

可直接补进研究任务背景的失败描述：

> 实测图虽然能辨认「弓」，但核心概念退化成“大字旁挂装饰”：汉字字芯约占画布 64% 宽、71% 高，压制了兵器与角色动作；所谓弓臂只是细三角折线，弓弦没有明确受力点，箭矢水平静置，缺少“拉满待发”的张力。两侧甲胄被生成成两个独立微型人物，缩到 64px 后成为噪点，弓臂、箭杆也只剩约 1px，职业识别基本消失。整体偏圆润可爱、奶油釉面和轻渐变，既不够武将化，也偏离纯平涂规范；朱砂与藤黄被拆成零碎装饰，阵营色没有成为大轮廓。原图还是 1254×1254 而非 1024×1024，背景只有约 9% 像素是精确纯白，存在轻微灰白漂移，不利于稳定自动抠图。

根因不是“装饰还不够多”，而是信息层级反了：

1. 「字」被当成平面徽标，而不是角色骨架。
2. 「武器」被当成小配件，而不是单位最张扬的外轮廓。
3. 「动作」没有受力关系，弓、弦、箭、双手各自独立。
4. 规范中的 8px 描边缩到 64px 只剩 0.5px，数学上无法承担战场识别。
5. 同一次生成同时承担字形、角色、武器、风格与抠图要求，模型会优先满足最容易的“大字 + 小装饰”。

## 2. 新的设计命题

一句话：**「弓」不是角色胸前的字，也不是一张字牌；「弓」本身就是正在拉满巨弓的武将。**

识别优先级固定为：

1. 先看到一张受力明显、即将放箭的巨大反曲弓。
2. 再确认它的核心骨架仍是完整、正确的汉字「弓」。
3. 最后读到我方暖色阵营与三国武将气质。

不再使用“汉字占画面约 60%”这类含糊表述，而使用三层包围盒：

| 层级 | 1024px 源图目标 | 64px 最终意义 |
|---|---:|---|
| 字芯「弓」 | 画布宽 42%–48%，高 50%–58% | 字仍是稳定识别中心，但不压住武器 |
| 巨弓 + 箭 + 字芯总剪影 | 画布宽 82%–90%，高 72%–84% | 兵种依靠大武器轮廓被认出 |
| 底部安全区 | 8% | pivot 与运行时地影空间稳定 |

## 3. 「字骨—兵器—人物」构形语法

### 3.1 字骨

- 参考图只负责锁定标准楷体「弓」的笔画拓扑、方向和两个主要负形。
- 必须保留完整三笔结构，不缺笔、不镜像、不生造、不把两个字腔粘死。
- 字面保持正视、基本直立；允许笔端向武器延展，但延展之前仍能顺着原笔画读出完整「弓」。
- 两个主要负形在 1024px 源图中净宽至少 48–64px，缩图后仍有约 3–4px 空隙。

### 3.2 兵器

- 「弓」的外侧长折钩笔画延展为一张粗壮反曲战弓的主弓臂；不是在汉字旁边另挂一张小弓。
- 上、下弓梢明显外翻并加粗，形成一眼可见的反曲轮廓。
- 弓弦从上下弓梢汇向一个明确的后拉点，形成受力清楚的 V 形，不得画成松弛折线。
- 箭已搭弦，向右上约 10°–15°，横跨画布 74%–82%；箭头和尾羽都夸张放大。
- 拉弦点相对弓把向后拉开画布宽度约 25%，让“蓄满”在静帧中成立。

### 3.3 人物

- 角色身体就是「弓」字，不再生成两个完整小武士。
- 只保留一对简化甲胄手：前手扣住弓把，后手捏住弓弦与箭尾；两只手都必须与字芯 / 武器相接。
- 最多再加一对宽肩甲和一个小盔缨，装饰总面积不超过主体约 15%，不得遮住主笔画。
- 姿态左右不对称、重心略前倾；张力来自弓臂变形、弦的 V 形和箭的斜向，而不是速度线、飞散粒子或背景特效。

### 3.4 为 64px 反推的几何下限

| 元素 | 1024px 源图建议 |
|---|---:|
| 主体最外轮廓 | 48–64px |
| 汉字 / 甲胄主要内部轮廓 | 28–36px |
| 弓弦、箭杆等最细关键结构 | 24–32px |
| 关键负形与构件间隙 | 48px 以上 |
| 阵营暖色覆盖 | 非透明面积 35%–45%，落在弓臂与大甲片 |

旧规范的 8px 可继续用于 UI 小装饰，但不适合作为单位角色在 1024px 源图上的唯一线宽。本轮先把 48 / 32 / 24px 作为实验值，以 contact sheet 的 64px 行决定最终数值。

## 4. 抠图友好的新解释

“一件主体只有一条闭合外轮廓”会把张开的弓、箭和拉弦姿态压成贴纸团块。本轮实验改为：

- 所有可见色块均为不透明、闭合黑边。
- 字芯、弓臂、箭、甲手之间必须相接或有 5%–10% 的视觉重叠，整体形成一个连通单位。
- 禁止漂浮碎片、墨滴、火星、烟尘、速度线和独立飘带。
- 水墨飞白、木刻刀痕、皮影纹样只能被裁切在主体内部，不能破坏外缘，也不产生细小 alpha 孔洞。
- 背景仍为精确纯白 #FFFFFF，无地影、无纸张纹理、无灰白渐变。

这只是 WO-A0 实验约束；正式入库规则要等实图通过 flood-fill / matting 后再回写。
