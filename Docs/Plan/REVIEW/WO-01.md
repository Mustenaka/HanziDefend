## 加分项

**1. 公式没有照抄字面量，而是把常数提进 `economy.json`。**
`armorScale: 100`、`refreshBaseCost: 15`、`refreshCostGrowth: 5`、`dropCoins: 1/3/20`、`minimumDamage: 1` 全部走配置注入，代码里零硬编码。这比逐字转录 §3.3 更符合红线三，是正确的过度履行。

**2. `Data` 引入 Newtonsoft 的姿势正确。**
`overrideReferences: true` + `precompiledReferences: ["Newtonsoft.Json.dll"]` + 保持 `noEngineReferences: true`。既拿到多态与字典支持，又没有破坏纯 C# 隔离，Json.NET 的反射被圈在 `JsonCodec` 一层里不扩散。

**3. `Rng` 的两个细节写对了。**
- `NextInt` 用 `threshold = (0u - range) % range` 的拒绝采样消除取模偏置，不是廉价的 `% range`
- `NextFloat` 取高 24 位 / 2²⁴，落在 `[0,1)` 且分布均匀
- seed=0 映射到固定非零常量（xorshift32 的零状态是吸收态），并有单测锁住

**4. `Math.Round(..., MidpointRounding.AwayFromZero)`** 而非 C# 默认的银行家舍入，并用 `2.5 → 3` 单测锁死。跨运行库的舍入歧义在数值系统里是经典暗坑，提前钉死是对的。

**5. 边界守得干净**：`Gameplay/` 目录至今仍只有 `BattleBootstrap.cs`，没有任何战斗/索敌/波次行为泄漏进来。
