## 0. 三个批次内的规格差异（先看这个）

| 组 | 底色 | 入库处理 | 混合模式 |
|---|---|---|---|
| **特效 fx** | **纯黑 `#000000`** | 亮度转 alpha | Additive |
| 背景 bg | 不透明，任意底 | 无需抠图；tile 走接缝修复 | 普通 |
| 指挥官 cmd | 纯白 `#FFFFFF` | 常规抠图 | 普通 |

**特效必须黑底**：刀光火焰是加色发光素材，白底抠图会把浅色部分一起抠掉。
**投射物一律画成朝正上方（12 点）**，运行期代码旋转。

**FX 一律用 1024×1024 生成，不分比例**——入库时按 alpha 包围盒自动裁剪再缩放，
画布比例对 FX 没有意义（这点和 unit 不同：unit 的画布要对应占格）。
下表的「入库」列是裁剪缩放后的目标尺寸，不是生成尺寸。

## 2. 背景（5 张）

方案已定：**可平铺 tile + 装饰贴片 decal**，不做整张（理由见 `README.md` §7）。

| 文件 | 内容 | 比例 | 入库 |
|---|---|---|---|
| `bg_zhan_chang_tile` | 战场地面主材质 | 1:1 | 512² |
| `bg_can_qi_decal_01` | 残破军旗 | 任意 | 长边 ≤512 |
| `bg_shi_dui_decal_02` | 碎石堆 | 任意 | 长边 ≤512 |
| `bg_jiao_tu_decal_03` | 焦土烧痕 | 任意 | 长边 ≤512 |
| `bg_che_zhe_decal_04` | 车辙沟壑 | 任意 | 长边 ≤512 |

### 2.1 两条硬约束

**明度压到 25%~40%，饱和度低于角色一半。** 角色是高饱和 + 厚黑描边，背景一亮黑描边就糊在底上，
64px 下单位直接消失。这是整张背景唯一不能妥协的指标。

**视角是正交俯视**（角色是正面 3/4）。这种混搭在参考游戏里成立，是伪 2.5D 的标准做法。

### 2.2 不要让 AI 出「四方连续」

这是全套最容易翻车的一张。正确做法是**出一张普通的地面材质图（不提平铺）**，
然后脚本做 **offset 半格 + 接缝克隆修复** 变成可平铺 —— 比反复要求模型
「seamlessly tileable」可靠得多，`art_intake.py` 顺手就能实现。

### 2.3 可粘贴的 prompt（5 条）

```
设计一个游戏战场地面材质，正交俯视视角，深色低饱和的夯土与碎石，明度压得很低，没有明显的主体物件，没有光斑和高光。正方形构图。

设计一个游戏场景装饰件：一面倒伏的残破军旗，布面撕裂，旗杆折断。俯视视角。同时用白色底，不要有背景。

设计一个游戏场景装饰件：一小堆散落的碎石与断裂条石。俯视视角。同时用白色底，不要有背景。

设计一个游戏场景装饰件：一片焦黑的烧灼痕迹，边缘余烬。俯视视角。同时用白色底，不要有背景。

设计一个游戏场景装饰件：地面上的两道车辙沟壑，泥土翻起。俯视视角。同时用白色底，不要有背景。
```

> tile 那张不需要透明，直接不透明输出；4 张 decal 需要抠图，所以用白底。

## 4. 这批之后就只剩 UI 了

`ui_card_bg_*`（卡牌底 4 色）、`ui_btn_*`（按钮）、`ui_grid_cell_*`（网格格子）、
`ui_panel_frame`（面板九宫格）、`ui_hpbar_fill_*`（血条）。

**建议这批不出图，走程序化生成**：九宫格要求中心区完全纯净可拉伸、四边四角严格对称，
AI 基本保证不了，而且它们必须和文字排版精确对齐，AI 出的边距永远差几个像素。
用 Python 画圆角矩形 + 描边 + 回纹，或直接在 Unity 里用 Image + 圆角 shader，
更快、更可控、包体更小。让 Codex 顺手写进 `art_intake.py` 即可。
