# BATCH-01 · 角色生成清单

> **怎么用**：在 ChatGPT 里开一个对话，先传 3 张已认可的参考图（`Docs/Art/_inbox/` 里的弓），
> 然后一行一行贴下面的 prompt，一次一个角色。出完存成对应文件名丢进 `Docs/Art/_inbox/`。
>
> 全程手动，不用脚本、不走 Unity。风格由参考图扛，文字只补身份和占格。

## 规则

- **汉字字数 ≤ 占格数**（一格一字）。1×1 用一个字，2×1 / 1×2 用两个字，2×2 用三个字。
- 横向占格 = 横构图，竖向占格 = 竖构图。
- 统一句式：`参考前三张图片的设计风格，设计一个 {名称} 角色，{构图}。同时用白色底，不要有背景。`
- 一次只出一张，不满意当场重出，**不要换对话线程**（换了风格必漂）。

## 两个异构单位

`弩车` 缺右上、`冲车` 缺左下，是唯一需要额外一句话的地方：

```
弩车 nuc（缺右上）        冲车 chc（缺左下）
  ┌────┬────┐              ┌────┬────┐
  │ 主 │ 空 │              │ 主 │ 主 │
  ├────┼────┤              ├────┼────┤
  │ 主 │ 主 │              │ 空 │ 主 │
  └────┴────┘              └────┴────┘
```

模型不一定听「留空」，所以 `art_intake.py` 里加一道兜底校验：
抠图后把 alpha 切成 2×2 四份，缺角象限覆盖率 **>8% 判不合格并标红**，≤8% 则把残留像素清零。
出图时如果连着两次没留出缺角，就改说法：
「弩车的绞盘和立柱都在左边，弩臂朝右前方低平伸出」「冲车的撞木前端悬空，车轮只在后方右侧」——
**用物体形态引导，比直接说"留空"管用**。

## 攻击态（idle 全部过审后再做）

```
以这张图为准，只改动作：{动作}。其他全部保持一致。
```

|---|---|
