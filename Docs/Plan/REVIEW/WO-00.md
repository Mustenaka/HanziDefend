**1. Mobile 质量等级仍指向模板 `Mobile_RPAsset`**

- `Mobile` → `Mobile_RPAsset`（guid `5e6cbd92…`，模板默认值，HDR/阴影/后处理都没关）

当前等级是 PC，所以字面验收标准满足。但本项目的真实目标平台是移动端（微信小游戏），移动构建会落到 `Mobile` 等级，届时拿到的是未调优的模板管线。
**处理**：把 `Mobile` 等级也指向 `HanziDefend_RPAsset`，或直接精简成单一质量等级。

## 建议项（不阻塞）

**2. 测试 asmdef 用了已废弃的旧式写法**

两个 Tests asmdef 用 `optionalUnityReferences: ["TestAssemblies"]`。现在能跑，但这是 Unity 2018 时代的字段。Unity 6 生成测试 asmdef 的现代形式是：
```json
"references": ["UnityEngine.TestRunner", "UnityEditor.TestRunner", ...],
"precompiledReferences": ["nunit.framework.dll"],
"defineConstraints": ["UNITY_INCLUDE_TESTS"]
```
`UNITY_INCLUDE_TESTS` 约束还能顺带保证测试程序集绝不进玩家构建——对微信小游戏的代码包体积预算是白捡的保险。有空时对齐即可。
