**3. 截图取证方式做了结构性改进。** 从"依赖异步阶段事件"改为"进入 Play 前 Editor pause + WAVE 0 硬门 + 每阶段 AutoRun 冻结确认"。首轮就是因为高速推进导致开局/中盘挤在同一时间窗、还漏了两张——这次是把取证机制本身修对了，不是碰运气重截。

## 建议项（不阻塞）

**1. 死亡淡出的白化，读起来像第三个阵营。**
`b4-mid` 里能看到大量白/粉色块混在红蓝之间。核对下来那是死亡淡出的中间态，不是配色 bug。但在密集战斗的一帧里，白块的数量足以让人误判成"还有一支白色部队"。
建议淡出改成**保留阵营色相、只降透明度与饱和度**，而不是往白色过渡。这样死亡过程仍然明显，但不会制造出不存在的第三方。

**2. 底部已部署缩略行被右侧截断。**
`卒 弓 火 冰 长矛 肉盾 大刀 轻…` 最后一个被切掉。现在 3×3 网格最多 9 个还好，网格扩到 7 列（最多 21 个部署位）时会严重溢出。
建议现在就定好策略（横向滚动 / 自动缩小 / 折行），别等 WO-C2 扩建做完才发现。
